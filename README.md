# Workshop Overview

This repository contains all teaching material, practical notebooks, datasets, and reference resources for the **IIMT Workshop on AI/ML for Antimicrobial Peptide Engineering**. The workshop introduces participants to computational peptide engineering, bioinformatics, protein language models, and machine learning approaches for antimicrobial peptide discovery.

# Getting Started

```bash
git clone https://github.com/rikmicrobio/IIMT-WORKSHOP-.git

cd IIMT-WORKSHOP-
```

Each `Day-X` folder contains:

- 📖 Theory presentation
- 💻 Hands-on Colab/Jupyter notebook
- 📂 Supporting datasets (where applicable)

The `references/` folder contains additional literature for further reading.
