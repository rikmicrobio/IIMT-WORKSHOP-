## How to Use

1. Clone the repo:
   ```bash
   git clone https://github.com/rikmicrobio/IIMT-WORKSHOP-.git
   cd IIMT-WORKSHOP-
   ```
2. Each `Day-X` folder has the theory slides (`.ppt`) and the hands-on notebook (`.ipynb`) for that day.
3. `references/` holds supporting papers and reading material for the workshop.
