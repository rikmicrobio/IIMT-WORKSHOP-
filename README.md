# IIMT Workshop — Module 4: AI/ML for Antimicrobial Peptide Engineering

Student Training Programme, Department of Biotechnology, IIMT University, Meerut
In collaboration with Structural and Protein Dynamics Lab (Hazra Group), IIT Roorkee

## How to Use

1. Clone the repo:
   ```bash
   git clone https://github.com/rikmicrobio/IIMT-WORKSHOP-.git
   cd IIMT-WORKSHOP-
   ```
2. Each `Day-X` folder has the theory slides (`.ppt`) and the hands-on notebook (`.ipynb`) for that day.
3. `references/` holds supporting papers and reading material for the workshop.
